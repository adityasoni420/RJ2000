# RJ2000

A luxury jewellery shop website for **Rama Rewellers**.

## Features

- Responsive gold-and-cream luxury design
- Gold, diamond, silver and bridal collections
- Custom jewellery section
- Manually add custom jewellery photos through the browser
- Live indicative gold and silver rate section in INR
- WhatsApp and phone contact areas

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Before publishing

Replace the placeholder phone numbers and showroom address in `index.html` with the shop's real details.

The custom gallery stores uploaded images locally in the visitor's browser. It does not upload them to a server. For permanent shared gallery management, connect a database or storage service.
